# ai-patterns

Скилл для ИИ-агентов (Claude и другие): убирает типичные шаблоны ИИ из результата, чтобы он выглядел так, будто его сделал конкретный человек для конкретного читателя.

Охватывает тексты, документы, таблицы, слайды, сайты и промпты для картинок. Это не список запрещённых слов: скилл учит заменять штампы конкретикой, реальными данными и осознанными решениями. Цель — качество, а не обход детекторов ИИ.

## Как это работает

1. Агент определяет тип результата и берёт нужные разделы скилла.
2. Пишет сразу по требованиям («Вместо»), а не исправляет потом.
3. Перед выдачей проверяет черновик по списку шаблонов и переписывает найденное.
4. Скилл не упоминается в ответе: вы получаете просто готовый результат.

## Установка

Скопируйте папку `ai-patterns/` в одно из мест:

- `~/.claude/skills/ai-patterns` (на Windows `%USERPROFILE%\.claude\skills\ai-patterns`), чтобы скилл работал во всех проектах;
- `.claude/skills/ai-patterns` внутри проекта, чтобы он работал только там.

Скилл включается сам при создании, редактуре или проверке текстов, документов, таблиц, слайдов, сайтов и промптов для картинок. Можно и вручную: попросите «проверь по ai-patterns».
